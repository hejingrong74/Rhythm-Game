# Rhythm-Game
Game Theory（FJ Rhythm Grid）是一款双键节奏游戏，内置同名曲目《Game Theory》。玩家使用 F 和 J 两键，配合动态判定区完成打击。游戏支持上传本地音乐，系统会自动分析节奏点并生成谱面；判定区会移动、旋转、跳动并变换几何形状，音符沿不同轨迹追向判定区，形成对称而有变化的视觉节奏。项目提供 Windows 封装版，解压后双击 GameTheory.exe 即可离线启动，无需安装额外环境。
Game Theory (FJ Rhythm Grid) is a two-key rhythm game that ships with the built-in track "Game Theory." Players use the F and J keys to hit notes against dynamic judgment zones. Local music can be uploaded, and the game automatically detects beats to generate a chart. Judgment zones move, rotate, bounce, and morph between geometric shapes while notes travel along varied paths toward them, creating a symmetric and expressive playfield. A Windows launcher is included, so after extracting the package, the game can run offline by double-clicking GameTheory.exe — no installation required.
